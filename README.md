# Card Battle Agent Lab

A static page showing how a hobby agent for a Kaggle card-battle simulation competition makes decisions, and how its versions did in local testing.

Live site: https://shubin123.github.io/card-battle-agent-lab/

This repository holds only the page and aggregate result numbers. It contains no agent code, simulator files, card data, decks, game logs or model weights. It's an unofficial project, not affiliated with the competition host or sponsor.

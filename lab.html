Teaching an agent to play a card battle.

This is a hobby entry for a Kaggle simulation competition, where submitted programs play full card games against each other. Here's how the agent decides, and how each version did in local testing.

How it was built

  1. Hand-written baselines. A linear ranking of option types, then a tactical heuristic that reads only public board information.
  2. Real games as training data. Simulated games on the competition simulator recorded every decision menu and the heuristic's score for each option.
  3. GPU training. A small neural network learned to reproduce those scores. Games were split into training and validation sets, so no game appears in both.
  4. Lookahead search. At each single-choice decision the agent guesses hidden cards from what it can see, plays every option forward to the end of its own turn, and keeps the option with the best resulting board.
